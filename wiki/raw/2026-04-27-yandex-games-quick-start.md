# Быстрый старт | Яндекс Игры

Источник: https://yandex.ru/dev/games/doc/ru/concepts/quick-start

## Размещение игры (6 шагов)

### Шаг 1. Ознакомьтесь с требованиями
Игра и материалы должны соответствовать требованиям.

Частые причины отказа:
- 8.2.3 — Интерфейс не переведён на заявленные языки
- 4.4 — Неправильно настроен показ рекламы
- 1.14 — Технические сообщения, ошибки, зависания, вылеты
- 5.1.3 — Несовпадение названия в игре и черновике на одном языке
- 2.7 — Возрастной тег не соответствует содержанию
- 1.15 — Недоработки/ошибки, мешающие пользоваться
- 1.10.1 — Важные элементы обрезаются границами игровой области
- 3.6 — Игра копирует другую игру из каталога

### Шаг 2. Подключите SDK или плагин
Добавьте код SDK в игру — обязательно для модерации. SDK управляет приложением: реклама, включение/отключение функций без обновления билда. Можно подключить через код или плагины.

### Шаг 3. Зарегистрируйтесь в Консоли
Нужен аккаунт разработчика в Консоли Яндекс Игр (games.yandex.ru/console). Указать предпочитаемый язык для связи на вкладке Профиль.

### Шаг 4. Загрузите игру
В Консоли: добавить игру → заполнить Черновик:
- Составить описания
- Добавить промоматериалы
- Локализовать на рекомендуемые языки
- Загрузить архив с файлами на сервер Яндекса

### Шаг 5. Подключите монетизацию
- Внутренняя и внешняя рекламная монетизация + инап-покупки
- Создать аккаунт в РСЯ (partner2.yandex.ru), принять соглашение
- Указать реквизиты для выплат и контакты
- Реклама: вкладка Реклама → Подключить монетизацию
- Покупки: запрос на games-partners@yandex-team.ru
- Выплаты при достижении пороговой суммы

### Шаг 6. Пройдите модерацию
- Самостоятельно проверить игру на соответствие требованиям (есть инструмент проверки в Консоли)
- В черновике нажать "Отправить на модерацию"
- Модерация: 3-5 рабочих дней
- Результаты в Консоли, при отказе — письмо на Яндекс ID с причинами
- После одобрения статус = "Опубликовано"
- После публикации: 1 неделя в разделе "Новые" + рекомендации подходящей аудитории
- Через 2 недели — рейтинг вовлечения и удержания
- Опция "Отсроченная публикация" для самостоятельного выбора даты

## Оперирование игрой (5 шагов)

### Шаг 1. Анализируйте метрики
Метрики в Консоли определяют сильные/слабые стороны. Целевые показатели:
- Рейтинг 80+ и ARPDAU > 2 ₽ = ощутимый доход

### Шаг 2. Проводите A/B-тесты
Инструмент в Консоли: эксперимент на части пользователей, каждой группе — свой вариант игры. Отслеживать метрики для определения удачных изменений.

### Шаг 3. Отвечайте на отзывы
Официальные ответы на отзывы игроков, редактирование игры по пожеланиям.

### Шаг 4. Выпускайте обновления
- Фикс багов
- Повышение качества контента, добавление нового, ивенты
- Учет изменений правил площадки
- История изменений платформы в release-notes, телеграм-канал @yangamesdevnews
- Улучшение метрик → органический трафик от платформы

### Шаг 5. Привлекайте игроков
Продвигать игру можно при: зелёный рейтинг + ARPDAU ≥ 1.5 ₽.
