# Yandex Games

Платформа браузерных игр от Яндекса. Каталог игр с монетизацией через РСЯ, внутренними покупками и SDK.

## Key Characteristics

- **Тип платформы**: браузерные HTML5-игры
- **Монетизация**: РСЯ (реклама) + in-app покупки через SDK
- **Устройства**: мобильные, десктоп, Android TV
- **Модерация**: 3-5 рабочих дней
- **Размер игры**: ≤ 100 МБ (разархивированный)
- **SDK**: обязательный, централизует авторизацию, рекламу, покупки, сохранения, язык

## Developer Console

- URL: games.yandex.ru/console
- Аккаунт разработчика — обязателен для публикации
- Указать предпочитаемый язык для связи (в Профиле)
- Черновик: описания, промо, локализация, загрузка архива
- Встроенный инструмент самопроверки игры перед модерацией
- A/B-тесты на части пользователей

## Metrics and Operations

- **Рейтинг 80+** и **ARPDAU > 2 ₽** = ощутимый доход
- Рейтинг вовлечения и удержания появляется через 2 недели после публикации
- Продвижение доступно при зелёном рейтинге + ARPDAU ≥ 1.5 ₽
- Органический трафик от платформы при хороших метриках

## Key Links

- РСЯ: partner2.yandex.ru
- Покупки: games-partners@yandex-team.ru
- Telegram: @yangamesdevnews

## Key Developer Limitations

- Вся коммерция (реклама, покупки) — только через SDK
- Внешние ссылки запрещены (кроме SDK кросс-промо и соцсетей с условиями)
- Гостевой вход обязателен
- Интерактивный ИИ запрещён
- YouTube-интеграция запрещена
