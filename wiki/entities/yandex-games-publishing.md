# Yandex Games: Publishing

Процесс публикации игры на Яндекс Игры и требования к промоматериалам.

## Step-by-Step Publishing

Согласно [[2026-04-27-yandex-games-quick-start]]:

1. **Ознакомиться с требованиями** — см. [[yandex-games-technical-requirements]]
2. **Подключить SDK или плагин** — обязательно для модерации; можно через код или плагины (см. [[yandex-games-sdk]])
3. **Зарегистрироваться в Консоли** — аккаунт разработчика (games.yandex.ru/console), указать язык для связи
4. **Заполнить Черновик** — описания, промоматериалы, локализация, загрузить архив
5. **Подключить монетизацию** — РСЯ-аккаунт, реквизиты; реклама через кнопку в Консоли, покупки через games-partners@yandex-team.ru
6. **Пройти модерацию** — самопроверка → отправка → 3-5 дней

## Moderation

- Срок: **3-5 рабочих дней**
- Проверка на окружениях, приближённых к пользовательским
- «Работает у меня» — не аргумент для снятия замечания
- Результат в Консоли, при отказе — письмо на Яндекс ID
- После одобрения: 1 неделя в разделе **Новые** + рекомендации аудитории
- Через 2 недели — рейтинг вовлечения и удержания
- Опция "Отсроченная публикация"

## Required Draft Fields

Название, Об игре, Как играть, Версия, Категории, Иконка, Обложка, Исходники, Поддерживаемые платформы, Ориентация + скриншоты

## Promo Materials

- **Геймплей ≥ 70%** площади (скриншоты) и длительности (видео)
- Запрещено: геймплей других игр, одинаковые материалы для разных игр
- **Иконка/обложка** — не скриншоты из игры
- Название идентично в игре и во всех материалах для каждого языка
- Название **уникально** в каталоге для всех выбранных языков
- Без рамок и скруглённых углов
- Без элементов системного/портального интерфейса
- Чёрный фон допустим только если он часть игры, а не заливка

## Post-Publishing Operations

- **Метрики**: рейтинг 80+ и ARPDAU > 2 ₽ = ощутимый доход
- **A/B-тесты**: эксперименты на части пользователей через Консоль
- **Обновления**: багфиксы, контент, ивенты → органический трафик
- **Продвижение**: при зелёном рейтинге + ARPDAU ≥ 1.5 ₽
- Telegram: @yangamesdevnews

## UX Requirements (for Moderation)

- Геймплей **> 10 минут** (викторины ≥ 100 уникальных вопросов)
- **Нарастающая сложность** и понятный сеттинг
- Сохранение прогресса (или рекорда для бесконечных игр)
- Описание управления — в игре или в сопроводительных полях
- Возрастной тег соответствует содержанию
- **Рейтинг > 30** — иначе через 3 недели снятие (2 недели на формирование у новых)

## Localization

- Минимум **1 язык** из выбранных в черновике
- Рекомендация: русский для ru/be/kk/uk/uz, английский для остальных
- **Автоопределение языка** через SDK — обязательно
- Игротексты, зависящие от языка — переведены

## Recommended (Optional but Desirable)

- Email для обратной связи
- Кнопка отключения звука
- Пауза геймплея
- Нет ошибок в Консоли разработчика
- Название без слов «игра»/«game», лаконичное
- Нет бесполезных кнопок (например, «выйти из игры»)
- Обучение для сложных механик
- Универсальные иконки для настроек/языка

## Prohibited Content

Политика, религия, эзотерика, насилие над детьми/животными, порнография, азартные игры, внешние покупки, вывод денег, внешние ссылки (кроме SDK кросс-промо и соцсетей с ограничениями), YouTube-интеграция

## Big Picture of Publishing (MDN)

MDN описывает [3 аспекта публикации](https://developer.mozilla.org/en-US/docs/Games/Publishing_games):
- **Distribution**: web = свобода дистрибуции, не locked в один store
- **Promotion**: линковость + shareability web vs store-ограничения
- **Monetization**: контроль платежей, без 30% комиссии

Yandex Games = конкретика для ru-рынка, MDN = общая стратегия.
