# Yandex Games: Technical Requirements

Критичные для архитектуры игры технические ограничения платформы Яндекс Игры.

## Hard Limits

- **Размер ≤ 100 МБ** (разархивированный архив)
- **index.html в корне** архива
- **Имена файлов**: без пробелов, без кириллицы
- **SDK обязателен** — см. [[yandex-games-sdk]]
- **Нет абсолютных URL на S3 Яндекса**
- **Интерактивный ИИ запрещён** (прегенерированные материалы ОК)

## Adaptivity and Display

- Элементы не деформируются при resize/повороте
- Нет браузерного скроллбара и swipe-to-refresh (своя прокрутка ОК)
- Элементы не перекрываются, не обрезаются за экраном
- Управление одной рукой, без доп. прокруток на основной сцене

## Devices: Required per Platform

### Mobile

- Полноэкранный режим
- Управление жестами (акселерометр как дополнение)
- Автопоказ клавиатуры при вводе
- Нет системного плеера, нет WebGL-уведомлений
- Лонгтап не выделяет поле/контекстное меню

### Desktop

- Активное поле до края (без стики-баннеров)
- Пропорции поля ≤ 1:2 (длинная к короткой стороне)
- Управление клавиатура/мышь по умолчанию
- Нет системных горячих клавиш
- Клик по полю не выделяет/контекстное меню

### TV (Android TV)

- Полноэкранный режим
- Управление стрелками пульта (+ Back, ОК)
- Покупки запрещены
- Нет ссылок на другие игры

## Supported Environments

- **Браузеры**: Яндекс Браузер, Chrome, Firefox, Opera, Safari, мобильное приложение Яндекс
- **ОС**: Windows Vista+, Mac OS X 10.6+, Android 5.0+, iOS 9.0+, Android TV

## Saves

- Прогресс сохраняется **сразу после действия** игрока (или по кнопке)
- Обновление страницы **не должно** терять данные
- Облачные сохранения — указать в черновике при публикации
- При покупках — прогресс на сервере, доступен с разных устройств

## Sound

- При сворачивании страницы — звук останавливается
- При полноэкранной рекламе — звук и геймплей на паузе
