# Yandex Games: Monetization

Способы заработка на Яндекс Играх и ключевые моменты.

## Two Revenue Sources

1. **Реклама** (РСЯ): interstitial, RV, стики-баннеры — через SDK
2. **Инап-покупки**: портальная валюта за реальные деньги — через SDK

## Setup

- Один partnerID на все игры
- Монетизация подключается через Консоль один раз
- Для каждой новой игры — автоматическая рекламная площадка со всеми форматами
- До публикации: тестовые блоки, после: реальные
- Покупки: запрос на games-partners@yandex-team.ru

## Ads: Required vs Optional

| Обязательное | Опциональное |
|-------------|-------------|
| SDK подключён | Настройка вызова рекламы в коде |
| РСЯ-аккаунт | Конкретные форматы (interstitial, RV, стики) |

Если реклама не планируется — указать в "Комментарий разработчика" при отправке на модерацию.

## Target Revenue Metrics

- Рейтинг 80+ и ARPDAU > 2 ₽ = ощутимый доход
- Продвижение доступно при зелёном рейтинге + ARPDAU ≥ 1.5 ₽

## Collaboration Forms

| Форма | Договор РСЯ | Договор покупки |
|-------|------------|----------------|
| Самозанятый | Да | Только как физлицо |
| Физлицо | Да | Да |
| Юрлицо / ИП | Да | Да |

## Strategy for Incremental

1. **RV за буст** — основная механика (не блокирует геймплей)
2. **Interstitial** между prestige-сбросами (логическая пауза)
3. **Стики-баннер** — пассивный доход всю сессию
4. **Инап-покупки** — pinch point на secondary валюте

См. [[yandex-games-sdk-ads]] для конкретных API-вызовов.
