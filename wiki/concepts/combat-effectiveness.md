# Combat Effectiveness

Сведение всех боевых параметров к одному числу. Метод из [[2026-05-16-gdcuffs-balance-series]].

## Base Formula

```
PW (эффективность) = HP * DMG
```

HP = суммарный урон, который юнит примет. DMG = урон за единицу времени.

Все параметры сводятся к этим двум, затем к одному.

## Parameter Reduction

| Параметр | Формула | Логика |
|----------|---------|--------|
| Крит | `DMG = DMG * (1 + CRIT%)` | 50% крит = +50% урон |
| Уворот | `HP = HP / (1 - DODGE%)` | 50% уворот = x2 выживаемость |
| Парирование | `HP = HP / (1 - PARRY%)` | Аналог уворота |
| Поглощение | `HP = HP / (1 - ABSORB%)` | Аналог уворота |

### Несколько эффектов

Эффекты срабатывают по очереди -- складывать нельзя:

```
HP = HP / (1 - (DODGE% + ABSORB% * (1 - DODGE%)))
```

ABSORB уменьшается на вероятность уворота: больше уворот -> реже поглощение.

## Coefficients for Non-Obvious Parameters

| Параметр | Коэффициент | Причина |
|----------|-------------|---------|
| Лечение | 0.7-0.8 к DMG | Целитель не всегда эффективен (один на поле / все здоровы / не лечит выше макс) |
| Условные бонусы | `эффект * доля_целей` | "+100 к урону по гоблинам" = +100 * % гоблинов среди врагов |
| Дальнобойность | Зависит от тактики | Нет точного матрешения. Влияет: можно ли закинуть ближнего прямо на дальнего, выгодность "танк спереди + стрелок сзади" |

Условные бонусы (интранзитивные механики по Шрайберу): пробитие брони, урон по зданиям, стойкость против типа -- считать через вероятность использования.

## Group Effectiveness

Умножение PW на количество недостаточно:

```
PW(N) = HP*N * DMG*(1 + 0.7*(N-1))    при N > 1
```

Коэффициент 0.7 = смертность членов отряда (DMG падает по мере гибели). Зависит от механик: распространенность AoE, дальность атаки отряда.

Упрощенная запись: `PW(N) ~ HP*DMG*N^2` для отряда с общим здоровьем и постоянным уроном -- но в реальности редко встречается.

## Ratings Over Percentages

Проблема: % параметры должны расти, но не могут >100%. 40% брони на 1-м и 100-м уровне = нет прогресса.

Решение: процент зависит от абсолютного рейтинга и модификатора врага:

```
Armor% = Armor / (Armor + Penetration)
```

Никогда >100%. Против равного врага с пенетрацией `Armor * 1.5` = 40% поглощения.

Пенетрация = отдельная прогрессия с множителем. Если нужен другой % против равного -- менять множитель.

## Parameters From Effectiveness

1. `средние HP, DMG = SQRT(PW)` (корень из эффективности)
2. Скорректировать: `HP = SQRT(PW) * SQRT(HP_multiplier)`, `DMG = HP / HP_to_DMG_ratio`
3. Коэффициенты к средним: танк = `HP * 1.5`, `DMG * (1/1.5)`

Ручное заполнение: вписать значения, столбец проверки (отклонение >10% = красный). Плюсы: красивые числа (666 урон), четные = толстые, нечетные = дамагеры. Минусы: больше работы, выше риск ошибки.
