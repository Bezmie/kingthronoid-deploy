# Core Loop Design

Общий фреймворк для проектирования gameplay loop и progression loop. Согласно [[2026-05-16-gdcuffs-core-loop-design]].

## Core Loop Structure

**Вызов -> Действие -> Награда**

Без основного цикла игра -- бессистемный набор механик. Игроки метаются в поисках способа играть, разочаровываются и уходят.

Примеры:
- Super Mario: Заметить -> Прыгнуть -> Выжить
- Шутеры: Прицелиться -> Выстрелить -> Продвинуться
- Minecraft: Исследовать -> Добывать -> Создавать

## 4 Time Scales

| Масштаб | Суть | Пример WoW |
|---------|------|-----------|
| Момент | Мгновенные действия | Заметить ресурс, избежать атаки, победить врага |
| Минута | Краткосрочные цели | Найти квест, наметить путь, выполнить |
| Час | Среднесрочные | Квесты, экипировка, таланты, торговля |
| День | Долгосрочные | Новые зоны, рейды, PvP, новые друзья |

Основной цикл = вложенные циклы, каждый подпитывает следующий. Успешный дизайн = цикл на каждом уровне.

## 7 Pillars of Player-Centric Game Design

| Столп | Без него |
|-------|----------|
| Ясность | Игрок не понимает, как взаимодействовать |
| Мотивация | Игрок не понимает, куда двигаться |
| Отклик | Игрок чувствует отстранённость |
| Удовлетворение | Нет ощущения прогресса |
| -- Вовлечённость | Нет эмоциональной глубины |
| -- Стратегия | Игра = рутина |
| Фантазия | Несоответствие сеттинга и геймплея |

## Progression Cycle

В мобильных/гача играх прогрессия важнее gameplay цикла. Структура = спираль с растущими вызовами/наградами.

**Два направления:**
- **Вертикальная** (мощность) -- числа растут, тот же контент
- **Горизонтальная** (вариативность) -- новые персонажи, навыки, стратегии

Гача: 1 персонаж -> 85 элементов прогрессии. 40 персонажей = 3600 микроцелей.

**Принцип**: новый контент требует новых вызовов. "Герой недели" не должен быть "героем года".

## How to Design

1. Начать с нескольких независимых циклов -> потом соединить
2. Проработать переходы между масштабами (момент -> минута -> час -> день)
3. Проверить каждый уровень на 7 столпов
4. Качество исполнения > количество циклов
5. Итеративный процесс: простые циклы -> постепенно усложнять
