# Gacha Probability

Вероятностные модели для систем со шансом-основанными наградами (гача/дроу карт/лутбоксы). Методы расчёта, ключевые механики, инструменты баланса. Согласно [[2026-05-18-gacha-probability-algorithms]].

## Base Formula

Для независимых пуллов с постоянным шансом (без pity):

`p = 1 - (1 - r * s)^n`

- `r` = rate (базовая вероятность тира)
- `s` = subrate (условная вероятность внутри тира)
- `n` = число пуллов

Замечание: формула точна только до порога pity. После -- нужен DP.

## Key Mechanics

### Pity

Нарастающий шанс после серии промахов. Определение: после N пуллов без попадания в тир, его rate увеличивается инкрементально. Сброс при попадании.

- Гарантирует получение за конечное число пуллов
- Управляет ощущениями: "долго не везёт" -> pity компенсирует
- Параметры: порог (pity_threshold), шаг (pity_step), максимум (hard_pity)

### Subrate / Rate-up

Условная вероятность внутри тира. P(target) = rate * subrate. Пример: event banner = 1 rate-up с subrate 50% -> P(target) = 0.02 * 0.5 = 0.01.

### Weighted Random Choice

Аналог в idle/roguelike: каждый тир имеет вес (weight). Вероятность тира = weight / sum(weights). Внутри тира -- равномерное распределение. Это одноуровневая модель (один roll). Двухуровневая: roll тира -> roll внутри тира.

## Calculation Methods

### Monte Carlo

Симуляция множества запусков. Плюсы: простота, универсальность. Минусы: приближение, зависит от количества запусков и качества ГСЧ. Сходимость по теореме Гливенко-Кантелли.

Когда использовать: баланс-тест, быстрый прототип, сложные механики где DP неприменим.

### Dynamic Programming

Состояние = (target_count, pity_count). Каждый пулл -- переход с известной вероятностью. Итерация по числу пуллов, обновление матрицы вероятностей. Даёт точные PMF/CDF.

Два подхода:
1. **(target, pity)** матрица -- прямое моделирование. Размер: (T+1) x max_pity
2. **(target, pulls_at_pity_0)** -- предвычисленные вероятности промах-серий. Только две строки в памяти. Эффективнее.

Когда использовать: точный баланс, "за сколько пуллов в среднем?", анализ чувствительности.

### PMF / CDF as Tools

- **PMF** (функция вероятности): P(target ровно на пулле n). Пик = самый вероятный пулл
- **CDF** (кумулятивная функция): P(target за n пуллов). Медиана = CDF = 0.5
- Среднее vs Медиана: среднее > медиана при скошенности (типично для гача). Медиана лучше для "типичный опыт"
