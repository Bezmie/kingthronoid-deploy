# Алгоритмы расчёта вероятностей гача (Kyle Chen)

Суммаризация статьи Kyle Chen (2025-01-30). Методы расчёта вероятностей получения наград в гача-системах на примере Arknights.

## Extracted Concepts

1. **Базовая формула** — p = 1-(1-r*s)^n для независимых пуллов. Точна до порога pity.
2. **Pity mechanic** — нарастающий шанс после промахов, сброс при попадании. Гарантирует получение за конечное число пуллов.
3. **Subrate** — условная вероятность внутри тира. Разные типы баннеров = разные subrate (standard 25%, event 50%, limited 35%).
4. **Монте-Карло** — симуляция множества запусков, сходимость по Гливенко-Кантелли. Приближение, зависит от качества ГСЧ и числа запусков.
5. **Динамическое программирование** — state=(target_count, pity_count), итерация по пуллам, точные PMF/CDF. Два подхода: полная матрица и двухстрочная оптимизация.
6. **PMF/CDF** — инструменты баланса: среднее > медиана при скошенности, медиана лучше отражает "типичный опыт".

Все концепции извлечены в [[gacha-probability]]

## Key Points

- Формула p = 1-(1-r*s)^n работает только без pity. После порога — DP
- Pity: после 50 промахов в Arknights rate растёт на +0.02 за пулл. Сбрасывается при 6-star
- DP подход 1: матрица (target+1) x 100 (pity max 99), итерация по пуллам
- DP подход 2: предвычисленные вероятности промах-серий, только 2 строки в памяти. Эффективнее
- Несколько баннеров: конволюция PMF через FFT (но подход 2 быстрее)
- Rust-реализация: github.com/astral4/aksim

## Project Application

- Дроу карт в kingthronoid = weighted random (одноуровневая модель, tierWeights)
- Pity для T2: гарантия после N дроу без T2 — улучшает ощущения игрока
- DP для баланса: точный расчёт "вероятность хотя бы 1 T2 за N дроу" при каждом drawLevel
