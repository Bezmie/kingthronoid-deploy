# MDN: Game Development (Суммаризация)

Mozilla Developer Network -- раздел веб-геймдева. 6 ключевых тем извлечены в wiki.

## Извлечённые концепции

1. **2D collision detection** -- AABB (rect-rect), Circle-Circle, SAT для выпуклых полигонов, broad/narrow phase (Quad Tree, Spatial Hash). -> [[collision-detection-2d]]
2. **3D collision detection** -- AABB (point/AABB/sphere vs AABB), Bounding Spheres, Sphere vs AABB (clamping), OBB. Physics engine как альтернатива. -> [[collision-detection-3d]]
3. **Tilemaps** -- tile atlas (spritesheet), static/scrolling/isometric, визуальные и логические слои, camera transform (world<->screen), dirty-tile оптимизация, off-canvas pre-rendering. -> [[tilemaps]]
4. **Web game loop** -- rAF как интеграция с browser main loop, DOMHighResTimeStamp, fixed timestep + rAF, Web Worker для off-thread update, tab visibility (pause vs simulate). -> [[game-loop-pattern]]
5. **Audio for Web Games** -- autoplay policy (user gesture required), mobile caveats (volume control disabled, buffering), audio sprites (one file + start/stop times), `<audio>` vs Web Audio API strategy (basic + enhance), positional audio (PannerNode). -> [[web-game-audio]]
6. **Cross-device input** -- Touch events (mobile first), mouse/keyboard (desktop), Gamepad API, Pointer Lock, device orientation. Adapt per platform. -> [[cross-device-input]]
