# Emergent Gameplay (Introductory Guide)

Alexander Brazie (25+ лет в AAA/инди: WoW, LoL, Ori). Полный гайд по emergent gameplay с примерами из реальных проектов.

## Ключевые тезисы

### Определение
Emergent gameplay — ситуации, где игроки делают вещи, возникающие из механик, но не запланированные дизайнерами.

### 3 фактора emergence
1. **Внутренняя мотивация** — игрок сам хочет что-то сделать, без внешнего указания (агентность)
2. **Непредсказуемость** — ни игрок, ни разработчик не ожидают этого (отличие от багов — правила консистентны)
3. **Системный геймплей** — построен на механиках и возможностях взаимодействия

### Примеры из реальных игр
- **Among Us**: Hide'n'Seek — не запланированный режим, обнаруженный через настройки
- **Fallout 1**: Pickpocketing = bartering code reuse → можно красть и подкладывать предметы
- **Skyrim**: Ведро на голове NPC блокирует vision → можно воровать
- **Pokémon Nuzlocke**: Самонавязанные челленджи сообществом
- **RimWorld**: Пересечение систем (needs + weather + combat + relationships) → cascade events
- **Minecraft**: Простые взаимодействия (blocks + crafting + redstone) → железные фермы, компьютеры в Minecraft
- **Ori**: Sequence breaks через physics glitches — разработчики не запретили, а убедились что игра не ломается

### Как дизайнить emergence
1. **Создавать много системных взаимодействий** — необходимые сложные системы + простые взаимодействия
2. **Поощрять исследование** — toy box, не box-and-hallway
3. **Принимать неожиданные моменты** — принцип «не затягивай поводья»

### Brute-force vs emergence
Baldur's Gate 3 (Larian) — brute-force: поддержать ВСЕ пути через огромный объём контента. Emergence — создать почву для неожиданного, не предвидя конкретные случаи.

### Предупреждение
Нельзя *создать* emergent gameplay намеренно — трата ресурсов. Лучше: создать игру, потом быть легче на поводьях. Работает лучше всего в single-player / PvE.

## Применение к Kingthronoid

У нас есть элементы emergence:
- ~~Shifting multipliers~~ (удалено 2026-05-01) + prestige + milestones комбинируются неожиданно для игрока. Текущий вариант: per-gen апгрейды × глобальные множители создают нелинейные комбинации
- Партиклы — визуальная проекция emergent-поведения (counts → экосистема)
- Принцип «не затягивай поводья»: если игрок нашёл оптимальный путь — не нёрфить
