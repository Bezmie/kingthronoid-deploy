# Проектирование основного игрового цикла (gdcuffs)

Перевод статьи [Core Loops in Gameplay](https://gamedesignskills.com/game-design/core-loops-in-gameplay/) -- системное руководство по проектированию gameplay и progression loops.

## Ключевые тезисы

1. Core loop = Вызов -> Действие -> Награда. Без него -- бессистемный набор механик
2. 4 временных масштаба: момент/минута/час/день. Каждый уровень = свой цикл
3. 7 столпов: ясность, мотивация, отклик, удовлетворение (вовлечённость + стратегия), фантазия
4. Progression loop = спираль. Вертикальная (мощность) + горизонтальная (вариативность)
5. Новый контент требует новых вызовов. Качество > количество
6. Проектировать: независимые циклы -> соединить -> переходы между масштабами

## Примеры

Minecraft (исследовать->добывать->создавать), Subnautica (survival + ориентиры), WoW (4-уровневая вложенность), FPS/RPG/Metroidvania/MOBA -- таблицы по 4 масштабам.

## Применимость

Для idle/incremental: core loop (клик->ресурс->апгрейд) покрыт в [[idle-game-core-loop]]. Данный фреймворк дополняет общими принципами: 4 масштаба + 7 столпов -- проверка качества проектирования.
