# Yandex Games Quick Start

Пошаговый гайд по размещению и оперированию игры на Яндекс Играх.

## Game Publishing: 6 Steps

1. **Ознакомиться с требованиями** — см. [[yandex-games-technical-requirements]], [[yandex-games-publishing]]
2. **Подключить SDK или плагин** — обязательно для модерации; можно через код или плагины
3. **Зарегистрироваться в Консоли** — аккаунт разработчика, указать язык для связи
4. **Загрузить игру** — заполнить Черновик (описания, промо, локализация, архив)
5. **Подключить монетизацию** — РСЯ-аккаунт, реквизиты; реклама через кнопку, покупки через email
6. **Пройти модерацию** — самопроверка → отправка → 3-5 дней → результат в Консоли

## After Publishing

- 1 неделя в разделе **Новые** + рекомендации аудитории
- Через 2 недели — рейтинг вовлечения и удержания
- Опция "Отсроченная публикация" для выбора даты

## Game Operations

1. **Анализ метрик** — рейтинг 80+ и ARPDAU > 2 ₽ = ощутимый доход
2. **A/B-тесты** — эксперименты на части пользователей через Консоль
3. **Ответы на отзывы** — официальные ответы + доработки
4. **Обновления** — багфиксы, новый контент, ивенты, учёт изменений платформы
5. **Привлечение игроков** — продвижение при зелёном рейтинге + ARPDAU ≥ 1.5 ₽
