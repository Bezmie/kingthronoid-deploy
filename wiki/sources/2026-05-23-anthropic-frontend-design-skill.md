# Frontend Design (Anthropic)

Репозиторий навыков Anthropic, `skills/frontend-design`. Выразительные фронтенд-интерфейсы продакшн-уровня. Фреймворк дизайн-мышления + эстетика анти-AI-slop.

## Key Points

1. **Дизайн-мышление**: перед кодированием — 4 вопроса: purpose (зачем, кто использует), tone (экстремальный выбор: minimal/chaos/retro/organic/luxury/playful/brutalist/art-deco/etc), constraints (фреймворк, перформанс, a11y), differentiation (что запомнится?)

2. **Осознанность важнее интенсивности**: и смелый максимализм, и утончённый минимализм работают. Ключ = intentionality (осознанность выбора), не intensity (сила воздействия). Чёткое концептуальное направление + точное исполнение

3. **Анти-AI-slop**: избегать типичной AI-эстетики. Запрещены: Inter/Roboto/Arial/system-шрифты, фиолетовые градиенты на белом, предсказуемые лейауты, шаблонный дизайн. Каждый дизайн = контекстно-специфичный характер

4. **Типографика**: выразительные + неожиданные шрифты. Пара: display-шрифт + утончённый body-шрифт. Избегать типовых

5. **Цвет**: единообразие через CSS variables. Доминирующие цвета + резкие акценты > робкие равномерно распределённые палитры

6. **Анимация**: приоритет CSS-only. Ключевые моменты: одна оркестрованная загрузка страницы (staggered reveals, animation-delay) > разрозненные микро-взаимодействия. Scroll-triggering + hover-сюрпризы

7. **Пространственная композиция**: неожиданные лейауты. Асимметрия, наложение, диагональный поток, нарушение сетки. Щедрое негативное пространство ИЛИ контролируемая плотность

8. **Фоны**: атмосфера + глубина. Градиентные сетки, шумовые текстуры, геометрические паттерны, многослойные прозрачности, драматичные тени, зернистые оверлеи
