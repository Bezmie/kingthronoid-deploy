# Yandex Games Requirements

Официальные требования к играм в каталоге Яндекс Игры. Модерация 3-5 рабочих дней.

## Key Points for Incremental Game Project

### Technical Limits (Architecture-Critical)

- **SDK обязателен** — инициализация строго по документации, вызов `LoadingAPI.ready()` когда пользователь может играть
- **Размер архива ≤ 100 МБ** (разархивированный)
- **index.html в корне**, имена файлов без пробелов и кириллицы
- **Сохранения**: прогресс сохраняется сразу после действия игрока, обновление страницы не должно терять данные; облачные сохранения нужно указать в черновике
- **Авторизация**: гостевой вход обязателен, Яндекс ID опционален после нажатия кнопки
- **Платежи и реклама** — только через SDK Яндекс Игр
- **Интерактивный ИИ запрещён** (заранее сгенерированные материалы допустимы)
- **Нет абсолютных URL на S3 Яндекса**

### Platform Requirements

| Аспект | Мобильные | Десктоп | ТВ |
|--------|-----------|---------|-----|
| Fullscreen | Обязателен | Активное поле до края | Обязателен |
| Управление | Жесты (+ акселерометр) | Клавиатура/мышь | Стрелки пульта + Back/ОК |
| Пропорции поля | — | Не более 1:2 | — |
| Адаптивность | Без деформации при повороте | Без деформации при resize | — |
| Покупки | Через SDK | Через SDK | Запрещены |
| Контекстное меню | Лонгтап не выделяет | Клик не выделяет | — |

Поддерживаемые браузеры: Яндекс Браузер, Chrome, Firefox, Opera, Safari, мобильное приложение Яндекс.
ОС: Windows Vista+, Mac OS X 10.6+, Android 5.0+, iOS 9.0+, Android TV.

### Ads

- Только РСЯ через SDK, сторонняя реклама запрещена
- Interstitial/RV: ставить игру и звук на паузу
- Rewarded video: добровольный просмотр, награда = бонус (не блокирует геймплей)
- Стики-баннеры — единственный допустимый доп. формат, кастомные RTB запрещены
- Модификация рекламных блоков запрещена

### Publishing and Moderation

- **Обязательные поля черновика**: Название, Об игре, Как играть, Версия, Категории, Иконка, Обложка, Исходники, Платформы, Ориентация + скриншоты
- Промоматериалы: геймплей ≥ 70% площади/длительности, иконка/обложка — не скриншоты
- Название уникально в каталоге, без слов «игра»/«game» (рекомендация), лаконичное
- Локализация минимум на один язык (рекомендация: русский для ru/be/kk/uk/uz, английский для остальных)
- Автоопределение языка через SDK
- Геймплей > 10 минут
- Рейтинг > 30 (иначе через 3 недели — снятие с публикации; 2 недели на формирование у новых игр)
- Нарастающая сложность и понятный сеттинг

### Prohibited Content

Политика, религия, эзотерика, насилие над детьми/животными, порнография, азартные игры, внешние покупки, вывод реальных денег, внешние ссылки (кроме SDK-ссылок на свои игры и соцсетей с условиями)
