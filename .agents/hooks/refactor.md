# refactor

1. При необходимости -- выполнить lint сначала для диагностики
2. Найти страницы с пересекающимся содержанием → предложить слияние
3. Cross-references: каждая страница должна ссылаться на 1-3 другие → добавить где не хватает
4. MOC-хабы: если по теме >=5 страниц → создать Map of Content (structure note) со ссылками
5. Противоречия: факты на разных страницах, противоречащие друг другу → пометить `[CONTRADICTION] ...`
6. Устаревшие: найти TODO/неполные → дополнить или удалить
7. Теги: проверить консистентность (одинаковые концепты = одинаковый тег)
8. Именование: kebab-case, короткие имена → переименовать если нужно
9. Выполнить фиксы с подтверждения пользователя
10. Запись в `wiki/log.md`: `core log refactor "кратко" --слито "N" --cross-refs "N" --MOC "список" --противоречий "N" --переименовано "список"` (или вручную)
