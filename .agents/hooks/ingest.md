# ingest

0. Если знания внесены минуя протокол (страница без source-трейсабилити, без записи в log.md) -- предложить откат и прохождение ingest заново
1. **Relevance pre-check**: до полного fetch оценить релевантность источника. Прямое совпадение = тег источника совпадает с тегом wiki-страницы. Проверка: `node wiki/bin/wiki.js tags <tag1,tag2>` -- если 0 страниц по каждому тегу источника, прямых совпадений нет. Если <2 прямых совпадений тегов -- предложить альтернативу или отказ. Косвенные совпадения (subject-area overlap) не считаются. Не тратить контекст на нерелевантные источники. **Override**: если <2 прямых совпадений, но пользователь явно запросил ingest этого источника -- разрешить с пометкой "user override". В log.md: "override: user-requested ingest при <2 tag match". Если 0 страниц по тегу -- ingest создаст первую страницу, это расширение wiki покрытия. Предложить: "0 страниц по тегу X. Ingest создаст первую страницу -- расширение покрытия. Подтвердить?"
2. Сохранить источник в `wiki/raw/` (если URL -- сначала fetch, потом сохранить)
3. `node wiki/bin/wiki.js ingest-prep <raw-file>` -- релевантные страницы, теги, покрытие
4. Прочитать исходный документ
5. Обсудить с пользователем: ключевые тезисы, что важно, что игнорировать. **Фильтрация "знание vs реализация"**: универсальные паттерны -> wiki, платформо-зависимая реализация -> игнорировать
6. Создать суммаризацию в `wiki/sources/YYYY-MM-DD-short-title.md` с frontmatter
7. Обновить или создать релевантные страницы в `wiki/concepts/` и `wiki/entities/` -- добавить новые факты, обновить cross-references. Использовать named edges (`uses::[[X]]`, `derived::[[source]]`, `caused::[[Y]]`) вместо plain `[[]]` когда семантика связи известна. Canonical edge types: uses, caused, fixes, supersedes, contradicts, derived
7a. Если при обновлении entity-страницы sources вырос до 3+ уникальных -- сообщить автору: «promotion candidate: [[page]] готов к concept (3+ sources)». Решение за автором
8. Стремиться затронуть 5-15 wiki-страниц при одном ingeste
9. **Hook guard**: создавать hook <=> процедура платформо-независима AND триггер однозначен. Иначе -- только wiki-знание. Декларативные паттерны (критерии, принципы, чеклисты) -> wiki concepts. Процедуры (шаги с триггером) -> hooks
10. Запись в `wiki/log.md`: `core log ingest "Короткое название" --создано "страницы" --обновлено "страницы" --тезисы "2-3 предложения"` (или вручную)
